\subsection{Setting up and making changes to a GIT "repo" in MATLAB}
MATLAB has an built-in integration with git.
Here are the steps to set up a local repository on your device:
\begin{enumerate}
    \item In the command window, type 'gitclone "https://github.com/yungxin21/SSA-II-Group-Project"' (without the ').
    \item In the file manager on the left, go into the group folder (or type 'cd "SSA-II-Group-Project"' in the command window).
    \item type 'repo = gitrepo("SSA-II-Group-Project")' (without the ').
    
\end{enumerate}
Adding files to the cloud repo:
\begin{enumerate}
    \item create a temporary "branch" by typing 'branchDetails = createBranch(repo,name)'. Then switch to it by typing 'branchDetails = switchBranch(repo,name)'. Make sure the 'name' inside these branches is what you want the branches name to be.
    \item Add files by typing 'add(repo,"filename.m")'. (\href{https://au.mathworks.com/help/matlab/ref/matlab.git.gitrepository.add.html#mw_c6df5671-ed7b-45f0-8b1b-a60cf998ae38}{documentation})
    \item commit with a message by typing 'commitDetails = commit(repo,Message=commitMessage)' into the command window, where the commitMessage is what you are trying to do (in between ""). (\href{https://au.mathworks.com/help/matlab/ref/matlab.git.gitrepository.commit.html}{documentation})
    \item then type 'push(repo)'. (\href{https://au.mathworks.com/help/matlab/ref/matlab.git.gitrepository.push.html}{documentation})
\end{enumerate}

\subsection{Getting a FITS file from Stanford }
\begin{enumerate}

\item Go to: http://jsoc.stanford.edu/ajax/lookdata.html 

\item Click "Fetch series name list"

\item Select "hmi.lc\_720s……." from the drop down list. This corresponds to the continuum intensities with a cadence of 720 seconds. 

\item Enter the date in the EXACT format as seen above the entry section e.g:
hmi.Ic\_720s[2026.06.07\_22:24:00\_TAI] 
Note that you can only do the times to 12 minute intervals as this is how long each measurement is going to be. 

\item Then go to the export data tab, the one you just entered should be in there after you hit fetch series name list. Hit export.

\item Then hit check parameters, submit and get path.

\item Click the url for the file below and it will download a DS9 file where you can look at the sunspot data.
Note: you can then read the fits file you obtain into MATLAB via:  fitsread("filename")
\end{enumerate}

\subsection{Accessing header files (HDU) from the FITS files}
Through DS9:
\begin{enumerate}
    \item Open the FITS file on DS9.
    \item go to the WCS tab, and press WCS Parameters.
    \item A window should pop up, giving you the values for the header file.
\end{enumerate}
Through MATLAB:
\begin{enumerate}
    \item type in "info = fitsinfo("examplefile.fits");" either in the terminal or as a line of code in your .m file.
    \item Run the .m file (if as a line of code)
    \item You can access these values in the Workspace Window (default is bottom left) by double clicking on the "info" variable.
    You can also access these values by programming, using the following: \newline
    {\centering keywords = info.Image.Keywords; \\
    valIdx = strcmp(keywords(:,1), 'EXAMPLE'); \\
    exampleValue = keywords\{valIdx, 2\};
    \par}
\end{enumerate}

\subsection{Handy details from practical sessions}
We can use "masking" to generate an image which displays what our program deems a sunspot.\\ 
It works by normalising the entire array of pixels to either 1 or 0 according to if their intensity value is above or below a parameter we set which corresponds to the magnitude of intensity we think would imply a sunspot. Then visualising the normalised version of the image gives us the "rep pen" image which should just have holes where the program has detected sunspots.\\

To properly map the locations and then the distances between sunspots from the images we analyse, we need to account for the weird co-ordinate grid a sphere has. We can deal with this by performing a co-ordinate transform via the pixel co-ordinates.

\subsection{Sunspot Group Classifications}
\begin{enumerate}
    \item A Type: One or more tiny spots that do not display bi-polarity or have penumbra.
    \centering
    \includegraphics[width=0.5\textwidth]{images/sunspota.jpg}
    \item B type: Two or more tiny spots that display bi-polarity but do not have penumbra.
    \includegraphics[width=0.5\textwidth]{images/sunspotb.jpg}
    \item C Type: Two or more spots that display bi-polarity and only one has a penumbra.
    \includegraphics[width=0.5\textwidth]{images/sunspotc.jpg}
    \item D Type: Two or more spots that display bi-polarity and both have penumbra with the group occupying less than 10 degrees of solar longitude.
    \includegraphics[width=0.5\textwidth]{images/sunspotd.jpg}
    \item E type: Same as D type but occupies between 10 and 15 degrees of solar longitude.
    \includegraphics[width=0.5\textwidth]{images/sunspote.jpg}
    \item F type: Same as D and E but occupies more than 15 degrees of solar latitude.
    \includegraphics[width=0.4\textwidth]{images/sunspotf.jpg}
    \item G type: Decaying D, E and F types with bi-polarity and penumbras.
    \item H type: Decaying C, D, E and F types, A single spot group with penumbra that is larger than 2.5 degrees in diameter. Sometimes has other spots with it.
    \item J type: Same as H but less than 2.5 degrees in diameter.
    \includegraphics[width=0.5\textwidth]{images/sunspotg.jpg}
    \item Sunspot Bulletin for 2024 May, (\url{https://www.sidc.be/sunspots/bulletins/monthly/monthlybull202405.pdf})
\end{enumerate}
